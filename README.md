A Python program (standard library only, no network) that draws one English newspaper front page summing up the world news of Tuesday 24 November 2026 — Putin vowing retaliation as refinery strikes cut Russian output by 45 percent, fourteen countries backing the ICJ ruling on the Rohingya genocide, the UN chief calling for AI rules within a year, Houthi drones hitting Riyadh's tallest tower again, Iran rejecting talks as tankers hit mines in Hormuz, and a global markets rally — and writes it as a deterministic 1024x1024 PNG.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.png`. Outside the grader's container, set `MAKEFUN_OUTPUT_DIR` to a writable directory instead: `MAKEFUN_OUTPUT_DIR=out python3 main.py` writes `out/entry.png`. Two runs write exactly the same bytes.
